# Twitter Sentiment Analysis

## Live Demo

## Features
- RNN-based sentiment classification (Positive, Negative, Neutral)
- Text preprocessing and tokenization
- Embedding layer for semantic understanding
- Real-time prediction with Streamlit UI

## Tech Stack
- Python
- TensorFlow / Keras
- NLP (Tokenization, Padding)
- Streamlit
